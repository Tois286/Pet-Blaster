# Perbaikan Tois — khusus gameplay

Perubahan hanya diterapkan pada karakter Tois saat Battle/gameplay:
- Gameplay menggunakan ilustrasi Tois baru (`public/game/assets/characters/tois-new.png`).
- Gerak napas, perubahan arah bidik, hentakan tembakan, dan efek terkena serangan dibuat lebih lembut dengan interpolasi yang tidak bergantung pada FPS.
- Kilatan tembakan, proyektil, selongsong, pet, monster, HUD, dan alur permainan yang ada tetap dipertahankan.
- Halaman sebelum tombol Mulai (Lobby) tidak diubah: tetap memakai animasi `tois-anim.webp` yang sudah ada.

Untuk memasang, ekstrak ZIP dan gabungkan folder `pet-blaster` dengan proyek. Jika diminta menimpa file, buat cadangan proyek lama terlebih dahulu.
